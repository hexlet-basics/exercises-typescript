
Implementa la función `unique()`, que elimina los duplicados de un array. La función recibe un array de números y cadenas. El resultado de la función debe ser un nuevo array en el que solo se conserve la primera aparición de cada elemento. El orden de los valores en el resultado se determina por el orden en que aparecen en el array.

```typescript
unique([9, 9, 3, 8, 8]); // [9, 3, 8]
unique(["twinkle", "twinkle", "little", "bat"]); // ['twinkle', 'little', 'bat']
unique([1, 1, 3, "oops!"]); // [1, 3, 'oops!']
```
