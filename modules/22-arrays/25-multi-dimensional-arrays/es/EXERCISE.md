
Implementa la función `getField()`, que genera el tablero de juego para el tres en raya. La función recibe la dimensión del tablero y devuelve un array de arrays del tamaño necesario, lleno de valores `null`.

```typescript
const field1 = getField(1);
console.log(field1);
// [[null]]

const field2 = getField(2);
console.log(field2);
// [[null, null], [null, null]]
```
