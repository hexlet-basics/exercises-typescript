
Implementa la función `reverse()`, que invierte un array. Técnicamente, debe devolver un nuevo array en el que los elementos estén en orden inverso. Usa el modificador `readonly` para el array de entrada. No uses el método incorporado `reverse()`.

```typescript
reverse([1, 2, 8]); // [8, 2, 1]
reverse([10, 33, 7, 0]); // [0, 7, 33, 10]
```
