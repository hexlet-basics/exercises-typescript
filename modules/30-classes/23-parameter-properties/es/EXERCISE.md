
Implementa la clase `CustomFile`, cuyo constructor recibe el nombre del archivo y el tamaño en bytes. Dentro de la clase define el método `toString()`, que debe devolver una cadena con el formato `<file-name> (<size> bytes)`. Usa propiedades de parámetros para rellenar las propiedades de la clase.

```typescript
const file = new CustomFile("open-world.jpeg", 1000);
console.log(file.toString()); // open-world.jpeg (1000 bytes)
```
