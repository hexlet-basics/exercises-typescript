
Implementa la función `last()`, que extrae el último elemento del valor pasado. El valor puede ser una cadena o un número. La función devuelve un valor del mismo tipo que se pasó como parámetro:

```typescript
// Pasamos una cadena como parámetro
// La función devuelve una cadena
last("hexlet"); // t

// Pasamos un número como parámetro
// La función devuelve un número
last(12345); // 5
```
