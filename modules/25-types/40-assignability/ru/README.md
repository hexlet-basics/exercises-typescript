В этом уроке мы разберем присваивание значения одной переменной другой. Это одна из базовых операций с переменными в большинстве языков. Самая частая ошибка, с которой вы столкнетесь в TypeScript, выглядит так: `Error: Type X is not assignable to type Y.`. Такой код не удается скомпилировать, поэтому нужно разобраться, как это исправить.

Присваивание значения одной переменной другой и передачу аргументом в функцию называют присваиваемостью (**Assignability**):

```typescript
let x: number;
const y: number = 10;
x = y;

function len(str: string): number {
  return str.length;
}
len(false); // Error!
```

И при присваивании `x = y`, и при передаче аргумента `len(false)` проверяется одно и то же: может ли принимающая сторона содержать передаваемый тип.

Если думать о типах как о множествах значений, то присваиваемость — это проверка, что множество значений источника входит в множество значений приемника. В `x = y` источник это `y`, приемник — `x`, и `number` входит в `number`, поэтому строка компилируется. В вызове `len(false)` источник это `false`, приемник — параметр `str`, а `boolean` в `string` не входит — отсюда ошибка.

Например, литеральный тип `'one'` входит в множество значений `string`, поэтому `const s: string = 'one'` компилируется. А множество значений `number` в `string` не входит, поэтому `const s: string = 10` — ошибка.

Значение типа `A` присваивается переменной типа `B`, если множество значений `A` является подмножеством множества значений `B`.

Так что когда вы в следующий раз столкнетесь с ошибкой `Type X is not assignable to type Y.`, не стоит сразу приводить всё к самому общему типу через `as any`: так проверка типов для этой переменной отключается полностью.

Сначала нужно разобраться, что ожидается на вход, и что возвращает функция. И только после этого можно модифицировать собственные типы: расширять допустимые типы, например, с помощью объединения и только в крайних случаях использовать хак с `any`.

Чтобы понимать, что к чему в TypeScript можно присвоить, нужно смотреть на код с точки зрения иерархии типов и структурной типизации. Этому посвящены следующие уроки в этом курсе.
