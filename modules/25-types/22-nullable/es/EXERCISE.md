
Implementa la función `formatPrice()`, que recibe un número y devuelve una cadena con el número redondeado a dos decimales. Si recibe `null` o `undefined`, debe devolver `'$0.00'`.

```typescript
formatPrice(3.145); // '$3.15'
formatPrice(200); // '$200.00'
formatPrice(); // '$0.00'
formatPrice(null); // '$0.00'
```
